# Pasta de Assets

Esta pasta contém os arquivos de mídia necessários para o portfólio:

## Arquivos necessários

1. **herminio-boca.jpg** - Fotografia profissional (recomendado: 450x540px em alta resolução)
2. **HERMINIO-BOCA-CV.pdf** - Currículo em PDF

## Como adicionar os arquivos

1. Faça upload da sua foto profissional e nomeie como `herminio-boca.jpg`
2. Faça upload do seu CV em PDF e nomeie como `HERMINIO-BOCA-CV.pdf`

Os arquivos serão automaticamente referenciados no portfólio.
